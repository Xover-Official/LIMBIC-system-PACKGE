# FactoryOS GUI Layout Map

## Overview
High-tech, industrial-cyberpunk aesthetic. Dark theme with neon accents (Cyan for ops, Amber for warnings, Red for critical/Red Flag).

## Pillars

### 1. Salary Loop (Pillar: Wealth)
- **Position**: Top-Left quadrant.
- **Components**:
    - **Current Balance**: Large digital readout.
    - **Income Stream**: Real-time scrolling list of credits.
    - **Tax/Deduction Indicator**: Small progress bar showing the "take-home" ratio.
    - **Wealth Velocity**: Line chart showing earnings over time.

### 2. Expense Loop (Pillar: Operations)
- **Position**: Top-Right quadrant.
- **Components**:
    - **Burn Rate**: Gauge showing hourly/daily spending.
    - **Resource Allocation**: Pie chart of where credits are going (Tokens, Actions, Maintenance).
    - **Efficiency Index**: Percentage indicating ROI on expenses.

### 3. Communication Loop (Pillar: Connectivity)
- **Position**: Bottom-Left quadrant.
- **Components**:
    - **Neural Uplink**: List of active connections to other agents/systems.
    - **Signal Strength**: Visual bars for each connection.
    - **Traffic Monitor**: Packet visualization for incoming/outgoing data.
    - **Trust Score**: Circular gauge for social reputation.

### 4. Red Flag Safety System (Pillar: Resilience)
- **Position**: Bottom-Right quadrant.
- **Components**:
    - **Threat Level**: Central alert status (Green, Yellow, Red).
    - **Risk Factors**: List of active concerns (e.g., Low Balance, High Arousal, Disconnection).
    - **Override Status**: Indicators for manual vs. automated safety protocols.
    - **System Integrity**: 3D wireframe representation of the agent's health.

## Inter-Loop Synergy
- Lines connecting the quadrants to show data flow (e.g., Salary -> Expense).
- Background "Industrial" noise/grid pattern.
